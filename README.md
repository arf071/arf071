### Projects
- **[SET: Score Event Tracker 🏐](https://github.com/arf071/set-score-event-tracker)** (Protohacks 2026): webcam volleyball auto-scorer with an Arduino scoreboard (LCD, LEDs, buzzer, servo flag). *Python, OpenCV, Arduino C++*
- **[Otter Tutor 👨‍🏫](https://github.com/ChrisColbourne/Hackathon26-/tree/main)** (StormHacks 2026): desk robot that watches a whiteboard and points a laser at a student's first mistake. *ESP32, Arduino C++, WebSocket*
- **Two-Stage Folded-Cascode CMOS Op-Amp:** 70.41 dB gain, 2.18 MHz unity-gain bandwidth, 0.66 mW. *Cadence OrCAD X, PSpice*
- **Two-Link Robot Arm Position Controller:** filtered PID design with 1.3% and 0.4% overshoot on the two joints. *MATLAB, Simulink, Simscape*
- **Digital Dice Roller (FPGA):** six-state FSM driving six HEX displays, verified with SignalTap II. *VHDL, DE1-SoC*
- **Automated Garbage Bin:** load-cell weighing with a stepper-driven bag-tying mechanism. *Arduino, HX711*
